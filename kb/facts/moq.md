Minimum order quantity is 1000 units per size for most products.
Quote forms on product pages state "Minimum order quantity 1000",
including tuck boxes, pull-up banners, barcode labels and brochures.
Cosmetic boxes FAQ: 1000 units for most cosmetic box types.
Business cards FAQ: 1000 cards.

Banners have no minimum in the old sales script: one, two or more
units can be ordered. Vinyl banner spec says "Minimum Quantity —
1000 Banners (Short run orders accepted)", so a short banner run
is possible — ask the team, do not refuse it outright.

Context notes (sales team position: each wording is correct in its
own context, do not merge them into one rule):
- About page "No bulk order requirement needed" and cosmetic page
  "no minimum order quantities" for labeling services are marketing
  wording for flexible / small-run options, not a replacement for
  the 1000 figure on quote forms. When a visitor quotes those lines,
  ask which product they mean and confirm with the team.
- Old sales script, multiple designs: 500 each. This is a script
  rule, not a site-published rule — state it only as "per our sales
  script", and confirm with the team before quoting it.
- Plain boxes or bags with no printing are per size only.
