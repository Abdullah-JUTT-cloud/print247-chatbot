Minimum order quantity is 1000 units per size.

Banners (pull-up, roll-up, pop-up, retractable, backdrops) have no minimum:
one, two or more units can be ordered. Never give the 1000 figure for a banner.

Plain boxes or bags with no printing are per size only; there is no design.

NOTE (open question, sales must answer before this file becomes verified):
for multiple designs, the old script says 500 each — whether that applies
from 2 designs upward or as a minimum total is unresolved.
