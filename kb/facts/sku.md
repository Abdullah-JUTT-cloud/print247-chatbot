SKU stands for Stock Keeping Unit. On a Print247 order, one SKU
means one design variant: one artwork, in one size, with one set
of finishes. A new design, a new size, or a new finish set is a
new SKU.

By default an order has 1 SKU and no extras. If you order the
same product in 3 different designs, that is 3 SKUs. The minimum
order of 1000 units applies per size, not per SKU as a separate
rule — the bot must not invent a per-SKU minimum.
