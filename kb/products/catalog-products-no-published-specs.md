## Consolidated note (dedupe, Oct 30, 2026)
This file replaces 13 near-identical catalog files (one per product
below). Those files differed only by product name: each said only
"product page, sold wholesale" + "no specification is available" +
the same quote-form fields + the same "Not stated" list. Keeping all
13 as separate chunks would have flooded vector search with 13
near-identical embeddings. No fact is lost here: every product below
had no published specification, and that is stated once, below.
